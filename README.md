# 餘光 AFTERLIGHT · 可玩 RPG 原型

沿用第一版的原生 JavaScript、資料目錄與獨立戰鬥引擎，重新製作 9:16 手機直式暗色奇幻介面、角色設定、能力收藏與方向式戰鬥控制。無第三方執行依賴、無素材下載、無需安裝遊戲引擎。

## 立即試玩

**電腦：用瀏覽器開啟 `PLAY.html`。** 這是包含所有程式、樣式與圖示的單檔版，可以單獨複製給別人。

開發時開啟 `index.html`，它引用同目錄原始碼。修改後執行 `node build.cjs` 重新產生 PLAY.html。

**手機直式遊玩：** 在電腦雙擊 `START-LAN.cmd`，或在此目錄執行 `node server.cjs`。手機與電腦連同一 Wi-Fi，輸入視窗列出的 `http://區域網路IP:8000`。電腦需維持該視窗開啟，若 Windows 詢問防火牆，允許私人網路即可。這是區域網路試玩，尚未公開發布。伺服器僅提供列入白名單的遊戲檔案。

世界 v1 的區域、地下城、獎勵池與測試方式詳見 [WORLD-V1.md](WORLD-V1.md)。

## 操作

| 操作 | 電腦 | 手機 |
|---|---|---|
| 移動 | WASD／方向鍵 | 下方中央搖桿，拖曳控制方向及速度 |
| 挑戰中立怪／查看遺跡 | 靠近後 E | 點按畫面中的互動提示 |
| 戰鬥普通招式 | W／↑、D／→、S／↓、A／←（另支援 1–4） | 點按下半部大型四方向招式 |
| 必殺技 | 空白鍵（另支援 5） | 點按中央大絕容器 |
| 本局資訊、自動成長 | B／右上按鈕 | 右上手札按鈕 |
| 設定／暫停 | 探索左上設定；Esc 暫停 | 探索左上設定，戰鬥右上 Ⅱ |
| 測試工作台 | 設定 → 測試工作台，或 F1 | 設定 → 測試工作台 |

切換分頁／失去視窗焦點會暫停。招式必須等目前讀條結束才能再次選擇。戰鬥中沒有逃跑按鈕，也不能打開手札換裝。

## 探索 HUD

探索時常駐介面只有左上設定、右上角色狀態、下方中央搖桿。隱藏血量／數值面板、小地圖、任務面板與技能列，將視野留給場景和角色。搖桿支援滑鼠及觸控拖曳、斜向移動、類比速度與中央死區；放手、觸控取消、開啟選單、失焦或進入戰鬥都會停止搖桿移動。

靠近地下城或可挑戰敵人時，搖桿上方才顯示情境按鈕；遠離即隱藏。地下城入口顯示推薦等級、敵人特色與可能獎勵類別。各城依資料採用 2／4／5 場結構。角色狀態內可開啟世界地圖，設定內可開啟世界測試工具。此版依規格移除舊探索展示中的 NPC、木箱、路碑與採集物件。

## 選單與 Build 規則

主選單包含「開始冒險、角色設定、能力庫存、設定」。角色設定分為能力、Build、裝備；角色插畫、五項能力與成長說明、四個被動技能、四個招式、一個必殺技及五個裝備部位皆可檢視。滑鼠懸停或鍵盤聚焦可看詳細說明，觸控長按可看提示。

能力庫存只能在出發前使用。技能、招式、魔法書依分類瀏覽，招式以 1–3 星標示永久等級；魔法書必須收藏且符合前置條件才可理解。出發前可加入／移除開局配置。

局內手札供檢視，升級自動提升五項能力，不能自由更換技能、招式、必殺技或裝備。地下城全波次完成後，首次獲得招式可當場選擇裝備或放棄；滿槽時先選替換目標，再按確認。放棄不會失去永久收藏；重複取得直接升級，不再出現替換選單。疾風靴於下一局出發前裝備。

戰鬥在上半部採只顯示置中的敵人，下半部整塊為四方向招式操作區。HP 紅色；MP 招式藍色、SP 招式橘色，液面表示剩餘比例，需求線表示最終消耗。四方向招式圍繞容器式必殺技，能量從底部填滿；充能完成顯示 READY，若資源不足仍會另外提示。敵人危險招式、讀條中斷、爆擊與閃避有不同回饋。切換探索／戰鬥有 0.55 秒轉場。

設定提供合成音效、音量、減少動態、高對比與全螢幕。音效在首次操作後才會啟用；全螢幕支援依瀏覽器而定。主介面採固定 9:16（480 × 853⅓ 邏輯像素）直式設計，等比例縮放。手機直向使用；電腦顯示置中的直式畫面。角色設定、能力庫存與彈窗可上下捲動，探索提供下方中央類比搖桿。

詳見 [戰鬥 v0.2 實作與測試說明](COMBAT-V02.md)，包含 50 技能、七屬性、工作台與暫定平衡。

音效事件包含 buttonHover、buttonConfirm、skillSelect、skillCast、damage、critical、levelUp、itemGain、dungeonEnter、ultimateReady、danger、interrupt。

## 永久與局內資料

- 永久資料：已學會技能、普通招式 Lv.1–3、必殺技、魔法書、裝備與武器、地下城完成次數。使用 localStorage key `afterlight.progress.v2`。
- 開局配置及偏好分別使用 `afterlight.loadout.v1`、`afterlight.settings.v1`。
- 本局資料：等級、EXP、配置、無上限招式等級、舊傷、倒下次數、探索狀態及地下城進度。現在每秒與重要操作後自動存檔，重開會自動接續。
- 新局從永久等級複製招式，不會把本局 Lv.4 以上存回永久等級。
- 收藏只屬於目前瀏覽器與網址；手機與電腦不會雲端同步。建議使用固定 HTTP 網址試玩與保存收藏；直接開檔的儲存支援依瀏覽器而定。
- 儲存錯誤會顯示提示，毀損／未知版本資料會安全回到初始收藏。此原型沒有伺服器帳號。

## 暫定平衡（集中於 data.js）

- 普通直接傷害：最大 SP／MP × 招式倍率 × 招式等級係數 × 裝備係數；未加防禦。爆擊最後乘上爆傷。
- 爆擊率：5% + 運氣 × 0.6%，上限 55%；爆傷：1.4 + 運氣 × 0.008。
- 閃避：敏捷 × 0.15%，上限 30%。EXP 運氣加成：每點 +0.8%。
- EXP 等級差節點：−15／−10／−5／0／+5／+10 對應 5%／30%／70%／100%／120%／150%，中間線性內插，兩端維持端點值。
- 招式每級額外倍率：Lv.2–3 +0.18；Lv.4–10 +0.09；Lv.11–20 +0.035；Lv.21 起 +0.012。無進化分支。
- 資源於開始讀條支付；中斷不退款。沒有場內自然恢復，必殺技可回復 SP。
- 同時出手時玩家先結算；中斷可取消敵人同時完成的讀條。敵人中斷後重新選招，每個地下城 Boss 使用其資料列定義的招式循環。
- 地圖是固定五區（7200×4200）加種子生成裝飾；出生點在安全營地周邊隨機，未製作完整世界生成。樹幹／岩石有玩家碰撞，怪物追擊採簡化直線 AI。
- 小怪每 65 秒探索時間重生；戰鬥與選單不推進探索時間。普通怪有 25%、精英有 75% 機率從區域池取得招式或技能。
- 目前採溫和的單能力 −8% 舊傷；前兩次倒下中止地下城，休養 8 秒後回營地恢復；第三次不復原。
- 必殺技充能在同局各場戰鬥之間保留，施放扣回零，新局才重置。讀條最低 0.5 秒，保留原公式。分頁卡頓時每幀最多模擬 0.05 秒，避免瞬間死亡。

這些都是方便試玩的可調設定，不是最終平衡。本版提供終末遺構 Boss 的內容骨架；平衡尚屬暫定，美術為程式繪製。依世界規格不含 NPC、任務與故事。

執行 `node --test --test-isolation=none engine.test.js progression.test.js combat-v02.test.js ui-flow.test.js world-v1.test.js offline.test.js balance.test.js run-summary.test.js`。

109 項測試通過，涵蓋戰鬥公式、成長與存檔、一次性能力獲取票券，以及以 DOM 適配器執行實際介面事件的完整流程：主選單、設定與收藏、方向招式、資源不足、中斷、升級、兩輪地下城、替換確認與取消、局內修改阻擋、三次倒下、魔法書與新局繼承，以及 PWA 安裝入口與直式設定。

另執行實際 Canvas 繪製程式，輸出手機直式 480×854 主選單背景、探索與戰鬥場景，檢查場景渲染；這些不包含 HTML 介面，並非瀏覽器截圖。

**驗證限制：** 此環境拒絕啟動瀏覽器子程序（EPERM／Windows 存取被拒），因此尚未完成真正瀏覽器版面、觸控及手機實機驗證。DOM 適配與 Canvas 測試不能取代瀏覽器測試。此版仍是可擴充原型，未公開部署。

目前戰鬥上半部不繪製玩家本體（含殘影人物），只保留敵人與必要資訊；玩家 HP/MP/SP 以操作區上方的簡潔條狀顯示。殘影仍保留追加傷害及斬擊效果。招式小浮窗位於下半部邊側，移開或取消會關閉；快速滑過與短按不會立即彈出。

## 整局收穫與大絕跨場充能

第三次倒下的整局結算會依招式、技能、裝備、魔法書列出本局取得項目，重複取得合併次數，新解鎖另行標示，招式顯示本局等級變化。基礎配置重新出發的確認畫面也顯示目前收穫。清單僅是已發放獎勵的紀錄，不再次領取。初始收藏不算本局收穫，放棄當場裝備的能力仍計入。

舊存檔無法回推先前掉落，顯示「舊存檔僅記錄更新後的收穫」。新紀錄與充能都會自動存檔。大絕只在戰鬥中隨時間累積，探索與結果畫面不額外充能；未使用的充能在同一局的一般戰鬥、地下城波次、休養後保留。施放後扣回零，之後重新累積；新局清零。

## 出生點石頭人與完全重置

营地左下方（190,510）有 Lv.18 沉眠石頭人，大型岩石造型，中立且不主動移動／追擊；靠近後互動才能挑戰。舊冒險存檔會補上這隻怪，不重複生成，也不重置其他敵人。

設定 → 完全重置 → 確認完全重置，會清除目前瀏覽器內的永久收藏、熟練度、通關紀錄、冒險、配置及偏好，返回全新遊戲。取消不做任何刪除。只移除本遊戲的四個儲存鍵，不使用 localStorage.clear，不清除其他資料或離線快取。
